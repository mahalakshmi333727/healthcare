# Image guide: content-matched photography

Every file below is currently a **neutral placeholder** (tone + simple pictogram, no text), because
real photographs could not be sourced or licensed inside the build environment. Replace each with a
licensed, realistic photograph **using the same filename and folder**. Layout, crop, `alt` text and
dimensions are already set up for these exact slots.

Rules for every photo: natural lighting, real medical equipment, natural expressions, no watermark,
no text inside the image, no distorted hands, no repeated photo. Keep the subject near the centre
(images use `object-fit: cover`). If a replacement shows a different subject, update the `alt` in `index.html`.
